
#  Saalsa – AI-Powered Emotional Travel Companion🌍✨

> **Machine Learning & Travel-Tech Innovation**
> Built with **Next.js, React, Node.js & AWS**
> SRM Institute of Science and Technology

---

## 🚀 Overview

**Saalsa** is not just a travel platform – it’s an **emotional travel companion**. Designed to transform **journeys into soulful storytelling**, it combines AI companionship, mood-aware planning, journaling, and gamified engagement to make travel truly memorable.

During pilot testing, Saalsa achieved a **25% increase in user retention**, proving that **emotions matter as much as logistics** in modern travel experiences.

---

## 🌟 Key Features

### 🧭 Onboarding Flow

* Interactive **“Travel Soul” Quiz** (4 archetypes)
* Personalized styling & results page
* Persistent archetype-based customization

### 😊 Mood-Aware Dashboard

* Daily mood check-ins with emotional emojis
* Weather-based responsive animations
* Archetype-based greetings & feature shortcuts

### 🤖 Raiza – AI Companion

* Gentle conversational interface
* Instant suggestions for common travel needs
* Warm & personal simulated responses
* Beautiful purple/pink gradient UI

### 📓 Saalsa Journal

* Emotion-tagged entries with vibrant visual tags
* Supports photos & voice notes
* Memory statistics & **PDF export**
* Drag-and-drop interface for memories

### 🗺️ SoulSpots Map

* Community-driven emotional travel spots
* Mood-based location filtering
* Heart-based ratings instead of stars
* Traveler stories to inspire journeys

### 🛫 Plan & Flow

* “Soul Blocks” instead of rigid itineraries
* Drag-and-drop planning system
* Emotional packing suggestions
* Elegant timeline view with rich cards
